## State Delta

**Destination sharpened.** The product is a view orchestrating multiple
concurrent Copilot Sessions with recursive delegation visible. The provider is
named: Copilot.

**The motivating defect is now recorded.** Uncontrolled Visual Studio Code
updates destroy Session state and force a manual rebuild of the working setup.
Restart reconciliation moves from one contract item among seven to the primary
acceptance criterion and the reason the product exists.

**A recommendation was made, tested, and retracted inside the cycle.** tmux was
recommended on the grounds that surviving the display host is desirable. The
user's requirement is the opposite. The retraction is recorded because the
reasoning was plausible and would otherwise recur. tmux is not disqualified as
an internal substrate, only as the persistence model.

**`Park` was defined wrongly and corrected.** It is not suspension of a running
process; it is persisting state, terminating processes, and reconstructing
later. Durable data, ephemeral processes.

**New confirmed requirements.** Deterministic process ownership and teardown
with zero orphans; a ceiling of 8 concurrent Sessions; resource metering inside
the Sessions panel with active admission control; a three-column layout with
global Session-scoped selection; delegation as a live tree with drill-in; a 1:1
Session-to-Primary-Agent binding enforced by a lock; and input-model continuity
as an adoption constraint.

**Vocabulary retired.** `Squadron`, `Squad Mate`, and `Swarm` are deprecated in
favour of `Sub-agent` and `Sub-agent tree`. The product carried four colliding
metaphor families - musical, military, biological, and nautical. Plain literal
nouns were chosen because the user's own adoption constraint makes any learned
vocabulary expensive. `Worktree`, `Parked`, and `Interrupted` were added.

**Maturity lowered one level to `researched`.** The tree recorded
`decision-ready`, but the form of the destination proved unsettled: within one
cycle the user floated neovim, the GitHub app, a Visual Studio Code extension,
and tmux as possible answers before resolving toward a built artifact.

**Two open conflicts recorded rather than silently resolved.** `Workspace`
