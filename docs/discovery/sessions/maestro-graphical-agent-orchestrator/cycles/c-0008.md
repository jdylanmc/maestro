## Corrections applied during confirmation

`/domain-mapping` stress-tested the staged definitions and rejected two. Both
corrections are now authoritative.

1. **A Fleet does not require a Worktree.** c-0007 made the Worktree
   constitutive while the same cycle settled that worktree-per-Fleet is a strong
   default rather than a rule, so a Fleet on an existing checkout would have
   failed its own definition.
2. **`Task` contains `subagent`, rather than equalling it.** The runtime treats
   shell commands as tasks, so not every Task is a tree node.

Two candidate decisions were assessed against the Architecture Decision Record
gate and **rejected** for failing it: worktree-per-Fleet, reversible per Fleet
by design; and the fully-generic display model, additive to reverse.

## Decisions

**File panes are read-only viewers with an "open in Visual Studio Code" action.**
No in-app editor is built for the MVP. This closes a contradiction open since
c-0005 between Issue #12's explicit deferral, the c-0005 wireframe's "basic file
viewer/editor", and the map's `Out of scope` wording that presumed editable
surfaces were required. The reasoning: the file pane would compete with a tool
the user already prefers and would lose, and the hard problems proven by c-0006
and c-0007 are lifecycle and isolation, not text editing.

**Closing Maestro auto-Parks every Fleet** - state persisted, processes
terminated, uncommitted work preserved - behind a pre-close summary naming any
Fleet with in-flight work or uncommitted changes. The decisive argument was
structural, not ergonomic: `Parked` and `Interrupted` are confirmed opposites
distinguished by deliberateness, so silent termination would make every Fleet
`Interrupted` and render the distinction decorative. Blocking the close was
rejected because `Ambiguous` is a real liveness verdict that could trap the user
inside the application. This resolves the c-0006 open item.

**`tracker-mode` moved from `markdown-only` to `remote`** under the exact
approval string, overriding the loop's recommendation to leave the tracker
stale.
