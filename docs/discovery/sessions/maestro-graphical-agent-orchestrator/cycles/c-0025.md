# Cycle c-0025

## Selection

**n-0011, deep. `selection-source: user`.** The cycle opened to record cmux as
the delivery route and ended by settling the scope of the product itself.

One question was asked. It was not a planned grounded question: the user asked
*"what is the scope of maestro? What does it do?"*, the loop answered by naming
the drift it had found, and the user chose between the two readings offered.

## The decision

`CONTEXT.md` defines a **Fleet** as "one feature, one Worktree, one Copilot
Session, its subagent tree, and its durable state". Over the preceding hour the
user had cut two of those five - enforcement (*"it doesn't have to be
enforced"*) and durable lifecycle state (*"just having the multiplex'd terminals
and tree structure is what i want"*) - and had interrogated the command surface
verb by verb until it collapsed to roughly one.

Asked to choose between **an observability plugin** and **an orchestrator being
built in stages**, the user chose the plugin.

**Maestro makes agent work visible inside a terminal the operator already
uses.** It reads the Copilot session's own event log and renders the subagent
tree, live, with status. That is the product.

## What this retires

Superseded in place with the reasoning intact, never deleted, because each was
confirmed on evidence and the record of a reversal is the point.

- **Enforced worktree-per-Fleet**, a hard rule since c-0010. Maestro observes;
  it does not police.
- **Durable `Parked` versus `Interrupted`**, identified in c-0022 as the largest
  remaining build item and as the reason Maestro was software rather than
  configuration.
- **Sweep on launch**, promoted to P0 in c-0021 as the *sole* teardown guarantee
  after `N0.1` was narrowed to best effort. With no lifecycle ownership there is
  nothing to sweep.
- **The command surface**, in its entirety.
- **Five route nodes.** n-0003 (Electron, built and promoted), n-0004 (WezTerm),
  n-0005 (Tauri), n-0006 (Swift), n-0012 (Zellij).
- **n-0007, the comparative technology evaluation. Cancelled, not deferred.** It
  consumes one executive report per register row to select a stack. The stack is
  selected, and the reports for the unbuilt routes will never be written.

## Why this is a destination rather than a retreat

The session's Destination was to find the smallest empirical sequence that could
prove or falsify the shared MVP contract. It did **both**: the contract was
larger than the problem, and the Host Application supplies nearly all of it.

Of the eighteen P0 requirements the user confirmed in c-0021, **cmux already
provides eleven**, **two became configuration in c-0024** - the file browser and
the editor hand-off, which had been specified as work - and the **subagent tree
is the only one the ecosystem does not have**. Two independent surveys of 190+
projects found nothing that renders a genuine parent-child agent hierarchy, and
the Copilot hook surface carries no subagent event at all, so the ecosystem
fakes trees by convention. The event-log join this session measured in c-0010,
revalidated in c-0020, and confirmed against live data in c-0024 is a path none
of them found.

Twenty-five cycles produced one component and a configuration file. That is a
successful discovery, not a failed one.

## The surviving product, and its measured defects

n-0011 is the only route left and is already running: the tree was observed
rendering live subagents into cmux's sidebar this cycle. Three reviewers were
run against it before installation, two of whom said **do not install as-is**.
Their findings are the frontier now:

- **The tree misses 73.4% of subagents** on logs above 8 MiB - measured across
  2,050 real subagents in 760 session logs - because of tail truncation. It
  fails *silently*, rendering a plausible tree, which is the same failure shape
  as `parentId`. The fix is incremental reads against the state store the plugin
  already has.
- **Session resolution is ambiguous.** It matches on `cwd` and takes the most
  recent write, so two sessions in one directory publish each other's trees.
- **`preToolUse` is registered and need not be.** It is the only path by which
  this plugin can deny a tool call, and it buys only live per-tool status.
- **No kill switch**, and a broken hook leaves the agent unable to uninstall it.
- The **PowerShell hook command is not fail-open**, so the plugin's stated
  invariant is false cross-platform.

What survived review: the join is correct (verified independently - 107
subagents, 0 unresolved), nothing sensitive is published, no injection is
possible, and performance is comfortable (35 ms + 30 ms + 44 ms).

## Domain consequence, staged

distinguishable from "a Copilot session running in a cmux workspace". Retiring a
term whose referent has dissolved is the `Workspace` (c-0007) and `Orientation`

This is material vocabulary change, it belongs to `/domain-mapping`, and it is
**staged rather than applied**. `ADR 0003`, which records hosting Maestro inside
an existing terminal, is strengthened by this decision.
