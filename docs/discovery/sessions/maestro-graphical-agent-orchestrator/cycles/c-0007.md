## Decisions

**Lifecycle is two independent axes** (`delegated-to-loop`). Durable Fleet state
carries intent - `Active`, `Parked`, `Interrupted`, `Failed` - while Liveness is
observed from process evidence each launch as `Alive`, `Dead`, or `Ambiguous`
and never persisted as truth. c-0006 observed a unit that was durably Active
while orphaned; a flat set cannot express that combination, and the combination
is the defect.

**Worktree-per-Fleet is the strong default, not a hard rule.** The user supplied
the driving intent, previously unrecorded: parallel units each working a
different feature in one large monorepo, isolated, and aware that others are
working. Verified consequence: worktree-per-Fleet implies branch-per-Fleet,
because two worktrees cannot check out the same branch.

**Maestro stays fully generic** (user override of the loop's recommendation).
It reads only generic runtime evidence and does not special-case any
orchestration skill, including `/ship-with-squadron`. The loop had recommended
a generic substrate with typed role adapters; the user chose no
orchestration-specific awareness at all. The accepted cost is that deadlines,
merge gates, ticket states, and the `AT_RISK` classification are unavailable.

**The structural unit is renamed `Fleet`.** One feature, one Worktree, one
Copilot Session, its subagent tree, its durable state. `Workspace` was proposed
and rejected as triple-booked across Copilot, Visual Studio Code, and this
model. This partially reverses c-0005's retirement of military metaphors; the
reversal was presented explicitly and accepted, on the ground that c-0005 was
rejecting *invented* vocabulary while `Fleet` is already spoken by both the user
and the runtime.

**`Agent` and `Primary Agent` cease to be domain entities** (`delegated-to-loop`,
then revised). `Agent` is reserved for Copilot's meaning, a selectable persona.
`Primary Agent` is retained as an interface term only.

**`Sub-agent` is respelled `subagent`** and **`Task` is adopted** for a tree
node's underlying runtime handle, both matching the runtime.

**Each Fleet has a primary agent window bound 1:1 to it**, always present, never
shared, never ambiguous. This specifies the main context window's default
content where c-0005 specified only its scoping.
